## [MONAD](https://causality.in/monad/)

Ask which distinctions survive when you compress or change a description. MONAD develops the mathematics in Lean, with a paper and a small Rust kernel.

<a id="muon"></a>

## [MUON](https://causality.in/muon/)

Design a common interface for one reasoning unit, so a stock model and a unit that learns from experience can be compared on the same work.

<a id="reckon"></a>

## [Reckon](https://causality.in/reckon/)

Run the same task at two memory budgets and see what changes. The local lab saves outcomes and shows which records were written, read or dropped.

<a id="hena"></a>

## [HENA](https://causality.in/hena/)

Ask whether small reasoning units can organise around a task when they can send only a few messages and keep only some of their past work.

<a id="q-muon"></a>

## [Q-MUON](https://causality.in/q-muon/)

Explore what a quantum implementation could change inside one reasoning unit while keeping MUON’s external interface.

<a id="q-hena"></a>

## [Q-HENA](https://causality.in/q-hena/)

Explore how quantum units might communicate, route work and share memory through entanglement. The design carries over HENA’s collective interfaces.

### Intelligence in a working system

Reasoning has to meet the work around it. RawThoughts’ products make one system of that work, with people deciding. [Pale](https://rawthoughts.in/pale/) (on RawThoughts) is the meta harness through which they act, a harness over the tools people already use; it carries a goal forward through people, agents and applications, with useful context and the decisions that need a person kept in view.

## Questions about the programme

**How do these projects fit together?**

Causality asks how a system can change its description and learn its own organisation, and these projects take the question in parts. MONAD asks what a change in description preserves. MUON studies one reasoning unit, HENA studies how units work together, and Reckon tests what memory contributes to a task. Q-MUON and Q-HENA ask related questions about a quantum unit and a quantum collective. Each page says what exists today.

**Where should I begin?**

For a small mathematical example, [follow a part from stock count to repair](https://causality.in/monad/descriptions-and-repair/): knowing it is available does not tell you whether it fits. To try an experiment, [give a classifier two different replay budgets](https://causality.in/reckon/compare-replay-budgets/) and compare how well it remembers its earlier tasks.
