Changing descriptions

What survives a changed question, a noisy observation or another representational basis?

This collection is about systems whose description itself changes.

A description offers a particular view of a thing. It may preserve every answer we currently need while collapsing states that a later question would separate. The difficulty appears when those states must become distinguishable again: is the answer merely hidden, was it discarded, or does the present language have no way to express it? Even when nothing is lost, different coordinates can leave us disagreeing about which quantities the description has recovered.

There is a bargain behind any useful description. We discard detail so that a problem becomes tractable, while expecting enough of it to survive for the next judgment. Storage, access, the language of the question and the permitted error all participate in that bargain. Its failure can demand another measurement, another representation or a narrower promise. Understanding which change is needed matters more than making the old account confidently answer again.
